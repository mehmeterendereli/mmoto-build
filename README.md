# MMoto build archive

> **Archived binary-distribution repository. These packages are not maintained or supported.**

This repository was used to publish historical MMoto application packages. It contains no corresponding application source, build definition, automated tests, or licence file.

## Release boundary

- Twenty-six historical GitHub releases remain attached to the repository.
- GitHub records a SHA-256 digest for the latest package, but the 627 MB asset was not downloaded or executed during the archive review.
- The packages must not be presented as currently verified, signed, safe, or compatible with a current operating system.
- No new release should be created from this repository without recovering the authoritative source, reproducing the build, scanning the output, and performing an isolated installation smoke test.

The releases are retained as historical artifacts only. There is no designated maintained successor.
